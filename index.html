Votre espace de gestion

Administration du campus

Version autonome, enregistrée sur ce navigateur. Vous pouvez gérer les documents, logos, textes et couleurs sans modifier le code. Il n’y a pas encore de compte administrateur sécurisé ni de partage entre appareils. Pour un site public multiutilisateur, un serveur, une base de données et une authentification sont nécessaires. Exportez régulièrement votre sauvegarde.

Ajouter un document à la bibliothèque

PDF recommandé. Taille maximale : 20 Mo. Ne déposez que les documents dont vous avez l’autorisation de diffusion.

Un classement simple, pour tous.

  1. Saisissez un titre précis et la matière.
  2. Choisissez le niveau et indiquez la spécialité. Toutes les spécialités peuvent être ajoutées librement.
  3. Joignez le sujet, puis cliquez sur « Publier ».

Votre document apparaîtra immédiatement dans la bibliothèque de ce navigateur. Vous pourrez ensuite le modifier, le télécharger ou le supprimer.

Le logo original n’est pas intégré automatiquement aux pièces jointes de cette conversation. Importez-le dans l’onglet « Identité du site » pour le rendre visible.

Nom, textes et visuels

Couleurs du campus

Cliquez sur une couleur pour la modifier. Conservez un contraste suffisant entre les boutons, les fonds et les textes.

Les images importées sont conservées dans le stockage local du navigateur, avec les sujets. Utilisez « Sauvegarde » pour pouvoir les restaurer ailleurs.

Conservez une copie de votre travail.

La sauvegarde JSON contient les paramètres, les logos et tous les documents. Gardez-la dans un endroit sûr : les fichiers peuvent contenir des données personnelles.

La restauration remplace les données actuelles, après votre confirmation. Exportez-les d’abord si vous souhaitez les conserver.
